# Explorando la Nasa

Aplicación interactiva que consume la **NASA API** para acercar el cosmos al usuario. Proyecto enfocado en Frontend, Clean Code y UX.

## Funcionalidades
- APOD: Consulta la Foto Astronómica del Día con traducción automática.
- Library Search: Buscador multimedia de archivos oficiales de la NASA.
- Local Storage: Sistema de favoritos persistente con monitor de telemetría.

## Tecnologías
- HTML5 & CSS3: Diseño responsivo con Glassmorphism y animaciones.
- JavaScript (ES6+): Lógica asíncrona (Async/Await) y Fetch API.
- APIs: NASA Open API & MyMemory (Traducción).
